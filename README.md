# Nexora product website

A dependency-free, ten-page product website for Nexora, maintained in its own repository. Source copy is based on the current console, API, and services. Twenty-one original SVG illustrations explain product workflows; console previews use explicitly illustrative data.

## Build and preview

Requires Python 3.9+; no packages or Node installation needed.

```bash
git clone https://github.com/Nexora-Distributed/website.git
cd website
python3 test_site.py
python3 build.py
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

Open `http://127.0.0.1:4173`. Pages also work under a GitHub project subpath. Set `SITE_URL` or pass `--site-url` when deploying at another HTTPS URL; this updates canonical URLs, sitemap, and the 404 navigation.

## Publishing

Source: [Nexora-Distributed/website](https://github.com/Nexora-Distributed/website). The Pages workflow uploads only the generated `dist` artifact. The website needs no runtime credentials, services, analytics, or browser network calls beyond its static assets.

[`.github/workflows/pages.yml`](.github/workflows/pages.yml) validates pull requests and publishes pushes to `main` using GitHub Actions. It can also be run manually. GitHub Pages is configured with GitHub Actions as its publishing source.

Live site: **https://nexora-distributed.github.io/website/**

## Edit

- `content.py`: page copy, navigation destinations, and the illustrative console.
- `illustrations.py`: original SVG artwork, regenerated by each build.
- `build.py`: shared HTML, metadata, sitemap, and 404 output.
- `assets/site.css`: responsive visual design and reduced-motion behavior.
- `assets/site.js`: accessible menu, preview tabs, command copy, and capability search.
- `test_site.py`: generated routes, internal links, fragments, metadata, SVG/XML, and tab wiring.

The website contains no account creation, sales form, live cluster connection, pricing claims, customer endorsements, or certification claims. Product features depend on provider configuration, permissions, ClickHouse version, and plan entitlements. Source access is required for the application installation commands.

## Feature coverage

Home, platform directory, observability, intelligence, SQL/data, operations, security, integrations, deployment, and getting started. The copy distinguishes implemented Kubernetes/cloud/on-prem deployment workflows from planned Terraform/Altinity discovery adapters; operator-supplied local AI from a turnkey offline bundle; and support target tracking from a staffed commercial SLA.
